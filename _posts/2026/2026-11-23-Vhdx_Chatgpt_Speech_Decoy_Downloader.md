## Vhdx Chatgpt Speech Decoy Downloader

A VHDX spear-phishing kit has been in use since at least September 2026. Each kit is a virtual disk with a document lure inside. Opening the **"document"** shows a real, well-written PDF, while a small program quietly asks a server what to run next. The lures range from a speech draft for a euro-policy event in Frankfurt to a National Bank of Moldova notice, Ministry of Finance rules, and a Moldovan tax-reporting procedure. Two of the decoys were generated by ChatGPT and carry a signed **"Content Credentials"** label from OpenAI to prove it. 

The delivery mechanism involves a ZIP archive containing a .vhdx virtual disk, leading to a shortcut dressed up as a PDF. The payload is a tiny downloader that fetches a command from a fresh .top domain and runs it hidden. Hiding tricks include a hidden folder, a window-less console, and a scrambled server address.

The five builds are clearly one kit, sharing the same loader and downloader sizes (102,912 and 134,144 bytes) and import hashes. Attackers favor the VHDX format because it gets past email filters and can also dodge a Windows safety net; files inside the disk were never downloaded themselves, limiting **"Mark of the Web"** tagging. Microsoft's November 2022 updates (CVE-2022-41091) aimed to fix this, though untagged files were still found afterwards. The mounted drive shows a single item with a generic document icon, which is a Windows shortcut (.lnk), sitting next to a hidden and system-marked folder.

The shortcut runs a command using `conhost.exe --headless cmd.exe /c .\eadregsad\Piroska_Nagy_Mohacsi_Opening_Remarks`. This starts a window-less command prompt that runs a two-line batch file. This batch file first starts the real PDF, so the victim sees exactly what they expected, and then runs an executable, such as `iutuysad.exe 9373fd0e-5eb0-49af-9e08-a64e66391211`. The GUID is the key to the server address. The DLL within the executable performs a reachability check by visiting `reddit.com`, `bing.com`, or `wikipedia.org`; if that fails, it silently stops to avoid running inside offline analysis systems. It then unscrambles the server, for example, to `2jcoasr[.]top` and `/starcraft`. It sends a GET over HTTPS on port 443, ignoring certificate errors, with a User-Agent pretending to be PowerShell: `Mozilla/5.0 (Windows NT; Windows NT 10.0; de-DE) WindowsPowerShell/5.1.19041.5737`. The reply is run as a command line, with no window or persistence.

The Piroska decoy, a four-page **"Proposed Opening Remarks"** speech, carries an embedded **"Content Credentials"** C2PA manifest. This manifest states it was created by: ChatGPT, model `gpt-6-thinking`, type: `trainedAlgorithmicMedia`, and signed by an **"OpenAI Media Service"** certificate on 2026-11-10 19:30:45 UTC. The label's hash matches the PDF's bytes, and the signature checks out against OpenAI's certificate chain, confirming ChatGPT's involvement. The Ministry of Finance decoy carries a similar label, naming ChatGPT model `gpt-6-astra`. This provides clear proof that attackers have started using AI-written lures. Each command domain is a fresh `.top` name; `2jcoasr[.]top` resolves to `217[.]60[.]196[.]158` in Frankfurt, registered to GOLD IP L.L.C-FZ in Dubai. The Moldova kits' servers, `naconda[.]top` and `tupnlaf[.]top`, sit on `5[.]175[.]253[.]236` and `5[.]175[.]253[.]235`. Notably, one build, the Piroska kit, has a typo: its loader asks for `asdeqasd.dll`, but the DLL on disk is `horialhsdk.dll`, causing a crash.
